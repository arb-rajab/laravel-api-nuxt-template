# Project memory

Durable project context that outlives a single working session. The files
here are empty scaffolds (headings only): fill them in as the project grows,
starting with `00-project-brief.md`.

Keep large, fast-growing files (the decision log, the session handoff) easy to
search: use stable headings and IDs so a future session can grep for the one
entry it needs instead of reading the whole file.

`../../scaffold-memory-pack.sh` re-creates any missing file without touching
existing ones.
